==================================================================
                     发票打印助手  ·  使用说明
       一个 PDF = 一张发票，自动按 A4「每张纸上下两张」拼版
==================================================================

【第一步】解压 + 安装（只做一次）
    1) 把压缩包整个解压出来（别在压缩包里直接双击）
    2) 双击文件夹里的「安装到本机.bat」
    3) 桌面上会出现一个图标「发票打印助手」

    安装脚本会做三件事：
    · 把程序复制到 D:\发票打印助手\（D 盘不存在时放到
      C:\Users\你\AppData\Local\Programs\InvoicePrintAssistant）
    · 在桌面建一个快捷方式
    · 启动一次程序，顺手把右键菜单装上

    × 装好以后，解压出来的那个文件夹可以删掉
    × 但程序目录本身（D:\发票打印助手）不能删，也不能只拷
      里面的 exe —— 它旁边还有一个 _internal 文件夹，缺了就跑不起来

【第二步】双击桌面图标，确认打印机
    看左上角「打印机」那一栏：

    · 显示「系统默认 · 某台打印机」= 跟随 Windows 默认打印机，一般就对
    · 要指定某一台，就在下拉框里选它（选完会记住）
    · 显示「未找到打印机」= 系统里还没装打印机驱动，得先装上

【第三步】把 PDF 拖到桌面图标上，就开始打印
    关掉界面也行，直接把发票 PDF 拖到桌面那个图标上。
    可以一次拖多个，也可以拖一整个文件夹（里面的 PDF 全收，
    包括子文件夹里的）。

    · 不会弹主界面，只在右下角出来一张小卡片显示进度
    · 打完自动关闭，程序自己退出
    · 每张发票独立一条打印作业，互不影响
    · 拖图标就是「现在就打」，不受界面里「拖入后立即打印」勾选的影响

    只打发票，不打别的：
    · 合同、报价单这类不是发票的 PDF 会自动跳过，不出纸（默认开启）
    · 开关在界面左侧的「只打印发票」；确实要打别的，取消勾选即可
    · 扫描件没有文字层，仍按发票正常打印，不会被误拦

    另外两种用法：
    · 双击打开界面 → 把 PDF 拖进中间的虚线框
    · 资源管理器里选中 PDF → 右键 →「使用发票打印助手打印」

------------------------------------------------------------------
  这一版为什么快
    以前是单文件 exe，每次双击都要先把自己解压到临时目录（180 MB 左右），
    光解压就 7 秒左右。现在改成文件夹版，程序直接跑，不用解包：
    点开基本就是秒出界面（实测 1.3~1.8 秒）。
------------------------------------------------------------------

  首次运行会做什么（不需要管理员权限）
    · 在 %APPDATA%\InvoicePrintAssistant 下建
      配置、打印历史、运行日志
    · 在当前用户的注册表里装一个右键菜单（界面上可以关掉）
    · 同一台电脑上装过更早版本的话，设置与历史记录会延续过来

------------------------------------------------------------------

【遇到问题】

  弹窗「Windows 已保护你的电脑」
      → 双击「解除锁定.bat」后再装一次；
        或者右键压缩包 → 属性 → 勾选「解除锁定」→ 确定，再解压。

  桌面图标打开提示找不到文件
      → 程序目录被移动或删掉了。重新解压一次，再跑「安装到本机.bat」。

  提示「没有可用的打印机」
      → 系统里没装打印机驱动。
        设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 添加设备。

  点了打印却弹「另存为」窗口
      → 默认打印机被设成了「Microsoft Print to PDF」。
        换成真实打印机；或者就留着它，等于把拼版后存成 PDF 文件。

  打完没看到历史记录
      → 打开界面看「历史打印记录」旁边的「共 N 条」；
        左侧面板底部的「数据文件夹」能直接打开存放位置。

  历史记录能删吗
      → 能。打开界面，在「历史打印记录」里选中一行或多行
        （按住 Ctrl / Shift 多选），点「删除选中」或直接按 Delete，
        确认后立即生效。只删记录，PDF 和纸票都不影响。

  同一张发票打了两次，第二次弹窗提醒
      → 程序会比对发票号后 8 位，重复时先问一句：
        默认「跳过这些」（不会重复出纸、也不写记录），
        确实要补打就点「仍然打印」。拖到图标上打印也一样会提醒。

  打印中途手滑点了窗口右上角的 ×
      → 不会中断：第一次点会提示「打完自动退出」，这一批打完
        程序自己关掉。真要立刻走，再点一次 × 并确认「立即退出」
        （强行退出时正在打的那张会中断，也不记历史）。

  已经开着界面，又双击了一次图标
      → 不会开出第二个程序，只会把原来的窗口调到前台。

  想换程序名字 / 图标
      → 名字只在 app/config.py 顶部两行（PROGRAM_NAME、UI_NAME），
        改完重跑 build.bat 即可；图标由 tools/make_icon.py 生成。

  想恢复全部默认设置
      → 删掉 %APPDATA%\InvoicePrintAssistant 这个文件夹。

  设置和打印历史存在哪？
      → 就在上面那个文件夹里。每台电脑各自独立，不会上传。
